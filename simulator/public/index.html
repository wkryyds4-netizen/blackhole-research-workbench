METHODS & PROVENANCE

每一条曲线，都有可追溯的来源

波形怎样生成

使用 Ripple 的 IMRPhenomD / IMRPhenomXAS 频域实现，双精度计算后逆傅里叶变换。20–25 Hz 与 900–1000 Hz 平滑收边，4096 Hz 固定采样。t = 0 对齐到正面观测的双极化包络峰值。

质量单位 M☉，距离单位 Mpc，应变无量纲。输入质量是探测器参考系质量，源参考系质量须乘以 (1 + z)。

哪些画面是示意

旋近轨道的相位取自波形，间距由主导模频率作 Kepler 近似。并合附近采用视觉过渡；遗迹图形不表示实际视界或其准正常模。

粒子环按当前峰值放大，拖动相机仅改变视角。动画倍速不改变数据或频率读数。声音按波形归一化，以原物理采样率播放。

真实信号怎样处理

GWOSC GW150914 v3，H1/L1 各32秒。首尾各10秒估计 Welch 噪声谱，整段白化后进行零相位35–350 Hz带通。模板经过同样处理。

对照在 −0.20 至 +0.08 秒窗口内拟合两个正交分量，并搜索 ±40 ms 平移。这是教学形状拟合，未联合天空位置、探测器响应或完整后验。

与形成渠道研究的关系

本工具展示“参数如何改变信号”。当前工作区的群体模型研究“参数总体及其探测偏好”。单次并合动画不能反推出唯一形成渠道。

后续接入联合后验和搜索注入时，需要补全自旋角、参考频率、天空位置等字段；偏对齐与各向同性仍保留为代理分量标签。
