## 2. 符号与公式审稿清单

- [ ] 用 N_obs=69 表示事件数，用 T 或 N_gen 表示注入有效归一化，避免N在同一式中两义。
- [ ] `f`只表示现象学偏对齐分量混合比例；`r=P(cos theta_1<0)`为主黑洞内禀比例；`a=P(theta_1<10deg)`为另一个积分量，不与自旋幅度a_i混淆（建议写F_10）。
- [ ] m1≥m2，q=m2/m1≤1；r不是“至少一颗逆行的BBH比例”，也不是探测样本中观测比例。
- [ ] 正确联合模型为 `f A_sigma(c1)A_sigma(c2)+(1-f)/4`，不是两份边缘混合相乘；后者会增加交叉分量并改变模型。
- [ ] 截断高斯支持[-1,1]，Z=Phi(0)-Phi(-2/sigma)，`B_sigma(x)=[Phi((x-1)/sigma)-Phi(-2/sigma)]/Z`。
- [ ] `r=1/2+f[B_sigma(0)-1/2]`；`a=u+f[v_sigma-u]`，u=(1-cos10°)/2，v=1-B_sigma(cos10°)。积分量区间由超参数后验逐点映射，不由平均PPD曲线直接给出。
- [ ] KL在共同可逆变换下不变；标准化位移/收缩比的不变证明限于仿射变换。跨sigma使用不同映射不能直接套用；自由sigma后验映射到r为多对一。
- [ ] 共同r先验明确是新条件化：R=[0.34173978699379726,0.5]，f_sigma(r)=(0.5-r)/(0.5-B_sigma(0))。它匹配r先验，不匹配整个倾角函数或a先验。
- [ ] 原uniform-f先验在相应区间截断、归一化，与共同uniform-r先验等价；条件化移除了原后验支持。必须报告被保留质量。
- [ ] 条件于事件数的似然 `prod_i mu_i(f)/xi(f)^N_obs`，不做率推断；固定质量、自旋幅度、红移设置不是联合超参数推断。
- [ ] IID经验bootstrap的精确均值协方差为 `sum_j w_ja w_jb/n²−mu_a mu_b/n`；注入以T替代n，包含零权重。它不带n−1修正，且不代表真实未知抽样设计已核实。
- [ ] logL协方差的一阶展开包含所有事件项和N_obs²选择项；模型差方差保留−2Cov。不同模型/参数点必须共享计数。
- [ ] `D=E_{r,r'~p0} Var[delta ell(r)−delta ell(r')]`；p0固定为名义条件后验，D不是每次bootstrap后验自适应加权，也不是单点logL方差。
- [ ] D=2[E_p0 Var(delta ell)−Var(E_p0 delta ell)]成立；D较小表示共同偏移被抵消，不是偏差为零的证明。
- [ ] 近1混合权重修正满足 `range(delta ell)≤N_obs log(wmax/wmin)`；这是修正函数在参数域上的振幅界，不是其绝对值界或总MC误差界。
