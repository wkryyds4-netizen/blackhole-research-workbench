### 对齐研究的实测结论

对 0389 的 Lev2/Lev3，统一用 Lev3 总参考质量缩放，以 `r=A−B` 比较 `Rz(φ)rLev2(t+Δt)` 与 `rLev3(t)`。固定拟合仅使用早期窗口，三个协议在相同的晚期窗口检验。

| 协议 | 晚期相对位置残差 RMS / Mref | 晚期分离度差 RMS / Mref |
|---|---:|---:|
| 共同原始坐标时钟 | 0.715163 | 0.0221652 |
| 共同视界时间平移 | 0.783951 | 0.000917904 |
| 早期固定时间＋相位拟合 | 0.187201 | 0.00583158 |

共同视界对齐显著减小了分离度差，却没有减小向量残差的 RMS。指标选择和对齐规则足以改变“哪个结果更接近”的判断。共同视界方法使用晚期标志，属于回溯比较，并非仅由早期数据预测。

早期拟合得到 Δt≈−3.28740 Mref、φ≈0.0509887 rad；训练 RMS≈0.00209 Mref，晚期验证增至≈0.18720 Mref。改变训练窗口后，验证 RMS 也改变，说明固定早期校准不能解释所有后期差异。不同窗口的数值不是置信区间，不以验证结果事后选择“最佳”协议。

该结果只涉及坐标诊断，未计算波形失配、收敛阶或形成渠道概率。方法与检查详见 `../alignment-results/README.md`。上阶段约0.123 M的分离度最大差使用了更宽时段；不能直接与此处独立晚期窗的 RMS 数值比较。

### GWSurrogate 实际运行

此前 MSVC 构建失败已通过工作区内便携 Zig/MinGW 路径解决。源代码数值公式未改动；修复了 Windows 整数 ABI、复数构造宏与动态库导出。该路径只核验本次 NRSur7dq4，并不宣称所有代理模型或官方 Windows wheel 都已支持。

固定输入 q=2，χA=(0.4,0.1,0.2)，χB=(−0.1,0.2,−0.1)，属于模型训练范围。以模型起始时刻定义自旋，时间约 −4300 至 +100 M，间隔 2 M，完整21个球谐模式保存在 `../surrogate-results/nrsur7dq4-full.npz`。

前端保留 `[w,x,y,z]` 四元数、惯性自旋、共进动轨道相位与 h22。没有位置、分离度或光学度规，因此单独使用方向球。h22 单位为 r h/M，未投影到某一观测方向或探测器。t=0 是模型多模式总振幅峰值约定，不必是 h22 峰值，也没有与 SXS 共同视界时钟对齐。

[模型论文](https://arxiv.org/abs/1905.09300) 第 III C 节说明，−100 M 后的延伸自旋仅用作晚期拟合参数，不具有物理黑洞自旋意义；界面在此截止方向显示，波形仍保留到振铃。

79项官方数值测试通过；2345组真实模型多项式独立核对的最大绝对差为2.78×10⁻¹⁶；旋转、范数、初始自旋与重复采样检查通过。主 agent 又实际重跑生成脚本，并核对前端四元数旋转与 SciPy 导出的方向。这是实现一致性检查，尚未完成与独立数值相对论波形的精度验证。复现、补丁与源文件校验见 `../surrogate-results/README.md`。

## 通用接口的进展

本阶段明确区分三类数据：`blackhole-scene/1` 保存有坐标位置的场景；`blackhole-alignment-study/1` 保存比较协议与验证残差；`blackhole-dynamics/1` 保存波形与框架动力学。缺失的物理量保持缺失，不通过给定一个虚构半径来强行合并接口。所有面板仍在同一工作台中切换。

源数据、适配器、分析和显示各有独立验证。SXS逐点反变换与原始网格误差检查覆盖七份场景；新前端六项数值接口检查、原九项协议/群体检查通过。浏览器检查和截图在本目录；上游79项测试记录在 `../surrogate-results/upstream-tests.json`。

## 下一阶段建议顺序

1. 读取未弃用进动算例的辐射波形，明确提取半径、外推/CCE、惯性系和迟滞时间；建立与代理模型可对比的同一参考频率和参数配置。
2. 在共同有效频段评估模式残差与探测器噪声加权失配，分别改变时间/相位对齐、总质量、倾角及高阶模式，并保留拟合与验证区间。
3. 只有波形比较可信后，再做参数偏差注入恢复。与群体研究对接时，使用完整联合后验和匹配搜索阈值的注入集，检验波形假设与选择函数如何共同改变渠道代理分量的后验。

当前尚未得到新的形成渠道比例估计。下一阶段的目标是验证波形系统误差如何传播，而不是从轨道或方向动画推断渠道。
