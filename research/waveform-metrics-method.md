# 有限波形记录的噪声加权失配

2026-10-23。实现为 `waveform_metrics.py`，验证为 `test_waveform_metrics.py`。只依赖当前适配器环境的 NumPy / SciPy。这里建立计算与诊断接口，不代表已经完成代理模型对独立数值相对论波形的精度验证。

## 比较对象与约定

必须区分两种比较：

- `complex_mode`：同一惯性坐标系、相同球谐约定的复数模式，例如 `h22`。同时保留正负频率，以 `S(|f|)` 加权。`h22` 在常用 `h=h+−i h×` 约定下可能主要在负频率；不能盲目只取 FFT 正半轴。这是模式形状诊断，没有指定观测者、天线响应或探测器网络。
- `real_strain`：调用者已经投影得到的单条实应变。使用正频率，最大化数学上的 Fourier 正交相位。对一般进动、多模态信号，这不是最大化真实轨道相位，也不是完整探测器网络失配；不得以该数学上限冒充物理相位拟合。

输入必须已在同一均匀网格上，且来源帧、模式规范、时间和质量缩放有单独来源记录。核心不会自动对齐峰值、旋转坐标或补全丢失的模式。`common_grid` 只在实际重叠区线性插值，拒绝外推；它不提供抗混叠滤波。粗化网格前必须确保信号带宽足够低并检验网格收敛。SXS 的 horizon 坐标时间不应直接当作辐射波形时间。

如果输入时间为 `t/M`，先选定探测器系总质量 `Mdet`，用 `dt_s = dt_M * Mdet * 4.9254909476412675e-6` 转成秒，然后才能用 Hz 的 PSD/频段。模式 `rh/M` 的整体振幅不会改变归一化失配，但它不是有物理距离的探测器应变，也不能据此给出 SNR。

## 离散定义

对原始有限记录先乘同一对称 Tukey 窗，默认 `alpha=0.1`，不去均值、不去趋势。`alpha=0` 是显式不加窗的敏感性实验。导出两条记录各自被窗去除的未加权功率比例，帮助识别窗口是否占主导；此比例不是误差估计。随后补零到至少 `padding_factor*N` 点，默认因子 4。

FFT 使用 `A_k = dt * Σ_n a_n exp(-2π i k n/Nfft)`，`df=1/(Nfft*dt)`。排除 DC 和 Nyquist；要求 `0<fmin<fmax<Nyquist`，在两端包含实际落入的网格点。输出实际频率边界、df、选中频点数。有限频段的锐利切除会使时域相关具有长尾，需要频段和补零敏感性检查。

复模式定义 `C(τ)=2 df Σ A_k conj(B_k) exp(+2π i f_k τ)/S(|f_k|)`，正负频率均计入；实应变定义为正频率求和且前系数为 `4 df`。范数使用同一频点与权重。因此归一化 `z(τ)=C(τ)/sqrt(Na Nb)` 中共同因子完全约去。代码进一步把 PSD 除以其中位数，仅为避免极端数值权重；不会改变归一化结果。

`match=max_τ |z(τ)|`，`mismatch=1−match`。固定时间相位匹配 `Re z(0)` 和仅优化全局相位的 `|z(0)|` 同时导出。输出 `τ` 表示将 b 变为 `b(t−τ)`；复模式再乘 `exp(i arg z)`。故若 b 是 a 延迟 d 秒并乘 `exp(iφ)`，恢复结果应为 `τ=−d`、相位 `−φ`。振幅最小二乘比例在允许的全局相位下为 `sqrt(Na/Nb)*match`。

时间搜索先在 `dt/oversample` 的网格上全局取最大值，默认 oversample=4；使用频谱嵌入的逆 FFT，而不是时间数据线性插值。然后在最佳网格峰周围一格范围内做有界连续精化，并比较搜索区两端。精化不保证发现网格没有解析出的所有窄峰，应通过 oversample 收敛检查。优化变化小于 5e-15 时保留网格解以避免数值噪声平移自匹配。允许的搜索范围小于半个记录时长；接近搜索边界时显式置 `at_time_boundary=true`。

补零保证原始有限记录不会在短延时搜索中直接环绕，但 PSD 加权和频带截断的相关仍有长尾，周期近似误差须通过增加 padding 检验。所有延时使用固定完整记录的范数，不随重叠长度重新归一化，也不从记录外生成新波形。全局常相位和时间优化只提供条件形状对比，不能修复错误的参考自旋、参考频率、模式旋转或不同起始段。

## PSD 与适用边界

`white` 为单位白 PSD，只做形状和实现检查。

`aligo_historical` 独立实现 [LAL 官方 LALAdvLIGOPsd 文档的数学表达式](https://lscsoft.docs.ligo.org/lalsuite/lal/_l_a_l_adv_l_i_g_o_psd_8c_source.html)：`x=f/215`，形状为 `x^(−4.14)−5/x²+111(1−x²+x⁴/2)/(1+x²/2)`，再乘 `1e−49 /Hz`。参考页面为 LAL 7.5.0.1-150d0ae 的生成文档，说明数据与拟合归属 Kip Thorne / B.S. Sathyaprakash。公式转写而非导入 LAL 源代码。这里给它明确的历史曲线名称；不称为当前运行噪声或精确的现行设计曲线。选择 10–2048 Hz 作为本工具的保守实验范围，该范围是本地策略，不是来源给出的校准保证。该历史曲线是否适合某一研究必须另外论证。

可传 `psd(f_positive)` 函数，必须在每个选中频点返回严格为正、有限的 PSD。调用者应在外层记录曲线来源、日期、单位、文件哈希及插值边界。默认不读 GW150914 的短窗 PSD，避免把一次事件的处理选择推广成通用探测器噪声。

## API 和结果记录

```python
from waveform_metrics import compare_waveforms, common_grid, MTSUN_S
t, a, b = common_grid(t_nr_M, h_nr, t_model_M, h_model, dt=0.5)
result = compare_waveforms(
    a, b, dt_s=0.5 * 65 * MTSUN_S,
    fmin_hz=30, fmax_hz=512, signal_kind="complex_mode",
    psd="aligo_historical", max_time_shift_s=0.01,
    taper_fraction=0.1, padding_factor=4, oversample=4,
)
```

该示例只有在两个输入的模式、坐标和参数已经对齐时才有科学可比性。`blackhole-waveform-metric/1` 记录 `match/mismatch`、平移/相位/振幅、未优化与仅相位优化的匹配、边界标志，以及全部数值配置。外层研究记录应增加源文件哈希、抽取/外推方案、坐标系、参数参考定义、质量和观测者、对齐协议、共同时间区间，以及预注册敏感性网格。不得根据最低失配事后选择预处理参数并只报告最佳值。

## 已执行验证

运行 `simulator/.adapters-venv/Scripts/python.exe research/test_waveform_metrics.py`。15 项测试覆盖：白/历史 PSD 自匹配；非整数延时、复相位和振幅恢复；实应变正交相位；不同包络非零失配；负频率约定；时间网格与补零收敛；振幅/PSD比例不变性；独立时域 Parseval 核对；搜索边界；有限记录端点不环绕；频段和无效 PSD 拒绝；输入形状/范数检查；插值不外推；严格 JSON 导出。

这些是数值方法验证，不是代理模型精度、SXS 波形收敛、物理形成渠道概率或观测数据拟合的验证。进入后续研究时需同时报告总质量、窗、低频截止、时间支持、采样、模式选择等敏感性，并把数值误差与物理模型差异分开。
