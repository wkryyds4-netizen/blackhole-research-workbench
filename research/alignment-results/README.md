# SXS:BBH:0389 两分辨率对齐敏感性研究

完成日期：2026-10-23。输入为固定的 [Zenodo 记录 3274661](https://doi.org/10.5281/zenodo.3274661) 中 Lev2、Lev3 的 Horizons.h5 与 metadata.json（CC-BY-4.0）；文件 SHA256 在 JSON 中保留并于每次运行前校验。

本研究直接读取原始视界数据，不使用经过可视化压缩的轨迹。SXS 将这些量定义为惯性坐标中的视界中心，并区分双星视界 A、B 与共同视界 C，见[官方说明](https://sxs.readthedocs.io/en/main/tutorials/03-Horizons/)。

## 研究问题与方法

当分辨率比较采用不同的时间、相位约定时，“两条轨迹有多接近”的结论是否稳定？固定参考为 Lev3，以其参考总质量 `M = 0.999988106301`（源文件单位）同时缩放两份数据的时间与长度，不分别重标两份数据。

取相对位置 `r = center(A) − center(B)`，比较 `Rz(phi) r_Lev2(t + delta_t)` 与 `r_Lev3(t)`。`Rz` 是绕**原始惯性 +z 轴**的常量右手旋转，映射到工作台坐标后对应 −y 轴。使用相对位置去掉共同平移，但不消除一般坐标规范依赖。

三种协议：

1. 共同原始坐标时钟：`delta_t = phi = 0`。
2. 共同视界平移：`delta_t = (tC_Lev2 − tC_Lev3)/M = −4.62547008`，`phi = 0`。这使用了晚期地标，属于事后比较，不能与“仅依据早期数据预测”的协议等同。
3. 早期固定拟合：仅在 `[670.007612, 1745.789540] M` 内最小化三维相对位置的均方残差；对时间偏移限定 `±30 M`，对每个偏移解析求最佳常量相位。先扫描 601 个偏移，再细化扫描发现的全部局部极小值并选择最优盆地。没有逐时旋转、变时伸缩、幅度拟合或使用验证窗调参。

三种协议均在相同的独立晚期窗口 `[3467.040624, 4973.135322] M`、相同的 2001 个均匀时刻评估。所有可能的 `±30 M` 时间偏移都在原始数据支持内，窗口末端留有额外的 `50 M` 余量。每个视界在自己的原始时间网格上作线性插值，禁止外推。

## 结果

| 协议 | 晚期相对位置 RMS / M | 晚期分离度差 RMS / M | 平面相位残差 RMS / rad |
|---|---:|---:|---:|
| 原始时钟 | 0.715163 | 0.0221652 | 0.0798253 |
| 共同视界平移 | 0.783951 | 0.000917904 | 0.0745319 |
| 早期固定拟合 | 0.187201 | 0.00583158 | 0.0209154 |

早期拟合得到 `delta_t = −3.287400871 M`、`phi = +0.0509886973 rad`。训练窗的相对位置 RMS 为 `0.00208944 M`，独立晚期窗增至 `0.187201 M`，说明一个固定早期校准无法吸收后续全部差异。

共同视界对齐显著改善了标量分离度，却没有改善向量 RMS。因此，只展示单一指标或只展示经过对齐的动画，会掩盖比较对约定的敏感性。相位残差定义为二维有向夹角 `atan2(cross(reference, comparison), dot(reference, comparison))`，不是引力波相位。

有效时段定义为所有允许时移都安全的区间 `[670.007612, 4973.135322] M`，长度 `4303.127710 M`。训练比例 `p` 指从这个区间的左端取 `p × 4303.127710 M`，不是完整仿真时长或轨道圈数的比例；验证窗固定取该区间的最后 35%。将训练比例从 15% 改为 25%、35%，保持验证窗完全不变，晚期相对位置 RMS 分别为 `0.236746 / 0.187201 / 0.143099 M`。这是协议敏感性，**不是统计置信区间**；不可事后选择验证表现最好的窗口并宣称预测精度提高。

## 验证与复现

从仓库根目录运行：

```powershell
simulator/.adapters-venv/Scripts/python.exe research/alignment_study.py
```

程序输出 `alignment.json`（完整曲线）和 `summary.json`（去除曲线的定量摘要），同时记录脚本 SHA256 和 Python/NumPy/SciPy 版本。

- 合成轨迹含啁啾相位、变化半径和 z 分量，已知偏移 `3.25 M`、旋转 `−0.43 rad`。恢复时间误差小于 `7×10⁻⁹ M`，独立验证轨迹最大误差小于 `7×10⁻⁹ M`。
- 验证正向旋转符号和旋转保范数；审计拟合函数查询时间，确认未请求验证窗值。
- 原始支持范围之外的查询必须抛错；真实训练/验证窗口即便加入最大时移也不重叠。
- 真实数据拟合点数从 1001 增至 2001，最佳时移改变 `0.00021983 M`，验证 RMS 改变 `0.00003334 M`。这检验训练采样选择，不能消除原始数据插值误差。

## 使用边界与下一步

只有两份分辨率，无法估计收敛阶或连续极限。坐标分离不是固有距离，轨迹差不是探测器可观测误差。本研究未计算波形失配、探测器噪声加权量或形成渠道证据；近无自旋算例上的固定 z 轴旋转也不构成通用进动对齐方法。

已有数值相对论论文展示了波形对齐改变报告的数值相位差，例如 [Scheel 等（2009）](https://arxiv.org/abs/0810.1767)。本文借鉴的是显式比较对齐约定的思路，未将波形方法的物理解释直接移植到坐标轨迹。

下一步应加入第三分辨率，检验误差的分辨率趋势；再独立读取辐射波形，显式处理视界坐标时钟与波形延迟时钟，在波形空间重复训练/验证分离的对齐研究。当前 JSON 可用于工作台对比图，图例须保留“坐标诊断”与单位说明。
