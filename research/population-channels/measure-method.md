# 四维渠道模型怎样接入七维事件与注入

本记录接续 2026-10-27 已公开的暂停检查点；当前目标已恢复。
本轮24组固定条件后验、独立数值核查及中英研究稿已完成，见 [阶段结果](RESULTS.md)。它们仍不是经过物理与活动误差校准的形成比例。

令 theta=(Mc,q,x,z)，x=chi_eff，s=(a1,a2,c1,c2)。公开渠道模型给出 p_c(theta)，
没有给出固定 theta 下的全部自旋条件分布。仅把 p_c 除以七维 PE 先验，
会混用不同维数的密度；仅在事件项中做四维边缘化，又不足以确定选择效应。

选定独立幅度、各向同性方向的自旋分布 Q(s)，记其有效自旋边缘为 f_Q(x|q)。
我们定义一个明确的提升模型

```
J(q) = dm1/dMc = (1+q)^(1/5) / q^(3/5)
p7_c(m1,q,z,s) = p4_c(Mc,q,x,z) * Q(s) / [J(q) f_Q(x|q)]
```

在固定 q 下积分掉未建模自旋后，该模型还原原来的四维密度。
但不同 Q 可以保留完全相同的 p4，同时改变完整波形似然和检出效率。
这正是本轮要测的模型假设；不是四维模拟器自己预测出的额外物理。

幅度均匀和 Beta(2,5) 是两个明确的压力模型。均匀幅度的单体投影为
log(A/|s_z|)/(2A)，Beta(2,5) 为 3/A*(1-|s_z|/A)^5。
二者的一维卷积给出 f_Q。批量算法在奇点处分段；前者用端点平滑后的
48 点 Gaussian 求积，后者在每个多项式片段用六点规则。
`fast-measure-validation.json` 对固定 714 点/族、归一化和解析二阶矩进行验证。
这验证实现，没有认证哪一个 Q 更符合真实形成物理。

这里的 Uniform/Beta 是构造 Q(s|q,x) 的基准律。提升并乘入给定 p4 后，
最终总体的自旋幅度边缘通常不再是该 Uniform/Beta 分布；它们也不是 CE 等
渠道已预测的完整分量自旋分布。不能据此把压力模型称为已验证的形成物理。

## 实际比较的定义

- 固定出生自旋 0.1、CE 效率 2，使用 log-alpha 的有条件解释。
- 限制到源系 m1∈[5,100]、m2≥3、q≤1、0<z≤1.9、|x|<0.99，
  并把提升分布的两颗自旋幅度限制在 0.99 内。
- 对每个渠道计算该四维域的归一化 Z_c。GC 的 q>1 样本不折叠；
  它们在该域的归一化指示函数中为零，仍保留计数。
- 本次五个 Z_c 的模拟器 MC 估计分别约为 CE 0.33539、CHE 0.61481、
  GC 0.66197、NSC 0.77760、SMT 0.68363，每渠道 262,144 个独立潜变量抽样。
  这些不是探测效率，也不是经过认证的真实总体支持率。
- 所有 69 个事件都保留，域外样本贡献零，但事件均值分母仍是其全部行数。
  O1/O2 及两份 O3 银行使用先前固定的条件规则，不把历史筛选未知项视为已解决。
- 对归一化渠道 p_c/Z_c 使用 eps=0、0.001、0.01 的共同正则分量。
  正则器在 (m1,q,z,x) 的限制域上为常数；换到 Mc 或七维时包含各自 Jacobian。
  它同时进入事件项与选择项。
- Dirichlet(1,1,1,1,1) 先验定义在限制域内的内禀分支比例上。
  不能把它直接称为所有宇宙双黑洞的形成比例。

若 A_ic 和 xi_c 是归一化后的事件积分和效率，则条件似然为

```
L(beta) ∝ product_i [sum_c beta_c A_ic] / [sum_c beta_c xi_c]^69
A_ic(eps) = (1-eps) A_ic(0) + eps U_i
xi_c(eps) = (1-eps) xi_c(0) + eps xi_U
eta_c = beta_c xi_c / sum_d beta_d xi_d
```

eta 是检出混合比例，beta 是限制域内内禀比例，二者分别报告。
同一 Q、同一正则化必须贯穿 A 和 xi。

## 数值失败与修复

原始直接乘法在 GW191230_180458 的 CHE/Beta 权重检查中得到约 1.5e-323，
独立计算约 1e-323，未通过原 1e-5 相对门槛。
这是 subnormal 舍入，不是可忽略记录的理由。旧实现、失败和已完成的九个
事件缓存保存在 `numerical-history/direct-weight-v1/`。
新实现合并对数后再求指数；不裁剪或删除困难样本。
同一门槛下，全部 69 来源的 1,970 个事件点和两份 O3 银行的 58 个随机/压力点通过，
最大权重相对差约 4.96e-10。检查包括独立标量卷积、距离积分、
标准正态流密度与 Cartesian Jacobian；不是全行独立重新积分。

`channel-log-*.json` 是修正后协议；`channel-event-integrals.json` 等不带 log 的
旧文件只保留修复前的历史，不得与新协议混合。完整计算与后验检验现已完成；修复前的部分事件缓存仍只作为历史，不用于新的渠道结论。

## 与文献的关系

[Callister 2021](https://arxiv.org/abs/2104.09508) 及其
[effective-spin-priors](https://github.com/tcallister/effective-spin-priors)
已给出质量 Jacobian、先验变换和均匀各向同性自旋的有效自旋先验。
我们的均匀族投影不是新公式；这里只增加批量求值、独立检查和明确条件分布对照。

[Colloms et al. 2025](https://arxiv.org/html/2503.03819v1) 已用五渠道流模型、
Dirichlet 分支先验、尾部正则化及选择修正推断出生自旋、CE 效率和渠道率，
并比较 KDE 与流表示。因此，接入五渠道或重复其层级似然不是本项目的创新。
当前增量是把其发布模型放入同一组已恢复来源的事件/官方注入对照中，
显式改变四维模型未确定的隐藏自旋条件，并检验正则化和搜索口径。
我们的限制域与固定超参数也使本次结果不能直接当作该文数字的复现或反驳。

后验求值器已在无信息及 69 个已知类别计数的解析 Dirichlet 实验中通过预设门槛。
这些是程序校准，不是实际引力波、PE 链、注入活动或物理模型的覆盖率校准。
完整积分、24组后验、独立乘积、科学图表及工作台适配现已完成。下一步是本批渠道积分的成对有限银行传播和真实物理补全；不能据此认证历史活动或宣称测得全宇宙形成比例。

补充重复风险：[Miller et al. 2024, 2401.05613v2](https://arxiv.org/abs/2401.05613v2)
已构造有效自旋分布相同而分量自旋不同的三个总体，完成事件和群体推断，
并说明模型错设诊断困难。
[Plunkett et al. 2026, Spinformation](https://arxiv.org/html/2610.18973v1)
进一步给出条件先验与超越有效参数的信息量诊断。
本研究不主张重新发现低维自旋摘要的非唯一性，也没有复现其信息量或 PPC 检验。
候选增量仅是同一五渠道公开库、同一 69 来源、两份官方 O3 银行与两搜索口径下，
这些明确条件补全对具体分支后验的传播；是否有独立科学价值须由实际结果判断。
