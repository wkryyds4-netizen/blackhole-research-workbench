# Numerical history

`direct-weight-v1/` preserves the first full-source run stopped after a failed
independent relative-weight check at a subnormal floating-point value. Its
implementation hashes, completed nine-event checkpoint and failure are retained.
These are audit snapshots, not executable reproduction entry points. Run the
current parent-directory tools instead. The revised log-weight protocol uses
`channel-log-*.json`; never merge records across the two protocols.
